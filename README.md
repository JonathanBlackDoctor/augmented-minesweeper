# MINE / SHIFT · 증강 지뢰찾기

숫자를 읽고, 증강을 고르고, 한 칸 더 나아가세요.

**[바로 플레이하기](https://jonathanblackdoctor.github.io/augmented-minesweeper/)**

설치와 로그인 없이 즐기는 한국어 지뢰찾기 웹 게임입니다. 탐사를 진행하며 능력을 선택하고 조합합니다.

## 플레이

- **탐사 / 심층 / 심연**: 9×9·10개, 12×12·24개, 16×16·48개 지뢰.
- 첫 클릭과 주변 8칸은 안전합니다. 이후 일부 보드는 추측이 필요할 수 있습니다.
- 클릭으로 탐색, 우클릭 또는 깃발 모드로 표시합니다. 숫자만큼 깃발을 꽂고 열린 숫자를 누르면 주변 칸을 엽니다.
- 시작과 탐사율 25%·55%·80%에서 증강을 선택합니다. 여러 기준을 한 번에 넘으면 차례로 선택합니다.
- **위상 보호막**: 지뢰 충돌 1회 방어 및 자동 깃발.
- **광역 스캐너**: 중심 칸을 선택해 3×3 지뢰·안전 표시, 2회 충전.
- **탐사 드론**: 숨겨진 안전한 칸 최대 3개 열기, 1회 충전. 빈칸은 연쇄 확장됩니다.
- 같은 증강을 다시 고르면 횟수가 쌓입니다. 능력 선택 중에도 탐사 시간은 흐릅니다.
- 방향키로 칸 이동, Enter/Space로 선택, F로 깃발 모드 전환.
- 모든 안전한 칸을 열면 승리합니다. 난이도별 최고 기록은 이 브라우저에만 저장됩니다.

## 개발 및 검증

외부 JavaScript 라이브러리나 빌드 과정이 없는 HTML/CSS/ES module 앱입니다. Google Fonts 로딩이 안 되면 시스템 글꼴을 사용합니다.

```sh
node serve.mjs
# http://127.0.0.1:4173
node --test
```

Node.js 20 이상 권장. 테스트는 모든 난이도 무작위 보드의 지뢰 수·첫 클릭·숫자 정합성, 깃발, 보호막, 스캐너, 드론, 승패와 주변 열기를 확인합니다.

GitHub Pages는 `main` 브랜치 루트에서 정적 파일을 제공합니다. 개인정보 수집이나 서버 전송은 없습니다. 기록 저장이 차단된 환경에서는 저장 없이 플레이할 수 있습니다.
