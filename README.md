# MINE / SHIFT · 증강 지뢰찾기

숫자를 읽고, 증강을 고르고, 한 칸 더 나아가세요.

**[바로 플레이하기](https://jonathanblackdoctor.github.io/augmented-minesweeper/)**

설치와 로그인 없이 즐기는 한국어 지뢰찾기 웹 게임입니다. 탐사를 진행하며 능력을 선택하고 조합합니다.

## 플레이

- **탐사 / 심층 / 심연 / 특이점**: 16×16·48개, 20×20·90개, 24×24·144개, 30×30·225개 지뢰(256 / 400 / 576 / 900칸). 심연과 특이점은 모두 지뢰 밀도 25%이며, 특이점은 판 자체가 더 큽니다.
- 첫 클릭과 주변 8칸은 안전합니다. 이후 일부 보드는 추측이 필요할 수 있습니다.
- **깃발 모드가 기본**입니다. 첫 클릭만은 깃발 모드에서도 안전하게 칸을 열고 시작하며, 이후 닫힌 칸을 누르면 깃발을 토글합니다. 탐색·깃발 모드 모두 숫자만큼 깃발을 꽂고 열린 숫자를 누르면 주변 칸을 엽니다.
- 시작과 탐사율 25%·55%·80%에서 증강을 선택합니다. 여러 기준을 한 번에 넘으면 차례로 선택합니다.
- **10종 중 무작위 3택1**: 매 선택마다 세 후보 중 하나를 고릅니다. 플레이 가이드에 전체 증강 도감이 있습니다.

| 증강 | 효과 | 선택당 충전 |
|---|---|---|
| 위상 보호막 | 지뢰 충돌 방어·자동 깃발 | 1회 |
| 광역 스캐너 | 지정한 3×3 안전칸 개방·지뢰 자동 깃발 | 2회 |
| 탐사 드론 | 무작위 안전한 칸 최대 3개 개방 | 1회 |
| 가로 레이더 | 가로 한 줄 안전칸 개방·지뢰 자동 깃발 | 1회 |
| 세로 레이더 | 세로 한 줄 안전칸 개방·지뢰 자동 깃발 | 1회 |
| 정밀 해체 | 지정한 닫힌 칸이 지뢰면 깃발, 안전하면 개방 | 2회 |
| 지뢰 추적기 | 깃발 없는 지뢰 최대 2개 확정·자동 깃발 | 1회 |
| 깃발 검증기 | 모든 깃발 검증, 오깃발 제거·안전칸 개방 | 2회 |
| 안전 굴착기 | 지정한 3×3의 깃발 없는 안전한 칸 최대 5개 개방 | 1회 |
| 경계 탐지기 | 경계 최대 5칸 안전칸 개방·지뢰 자동 깃발 | 2회 |

개방 능력으로 빈칸을 열면 주변도 연쇄로 열립니다. 어떤 능력도 지뢰 배치를 바꾸지 않습니다. 횟수는 실제 효과가 있을 때만 차감됩니다. 지정 능력은 사용 버튼을 누른 뒤 칸을 선택하며, 탐색·깃발 버튼으로 취소합니다.

- 같은 증강을 다시 고르면 횟수가 쌓입니다. 능력 선택 중에도 탐사 시간은 흐릅니다.
- 방향키로 칸 이동, Enter/Space로 선택, F로 깃발 모드 전환.
- 모든 안전한 칸을 열면 승리합니다. 승패·시간·탐사율·증강 조합과 난이도별 솔로 최고 기록이 이 브라우저에 저장됩니다.

## 친구와 1대1 대전

1. 상단 **친구와 대전 → 새 방 만들기**에서 난이도를 고릅니다.
2. 8자리 방 코드 또는 **초대 복사**로 얻은 링크를 친구에게 보냅니다.
3. 양쪽이 10종 중 첫 증강을 자유롭게 선택하고 **준비 완료**를 누르면 3초 카운트다운 후 시작합니다.
4. 같은 seed와 가운데 시작 칸을 사용합니다. 상대 탐사율을 실시간으로 볼 수 있습니다. 이후 같은 탐사율 단계의 증강 후보 세 개도 양쪽이 같습니다. 후보 추첨은 지뢰 배치와 독립적입니다.
5. 먼저 모든 안전한 칸을 열면 승리합니다. 보호막 없이 지뢰를 밟거나 대전 중 나가면 패배합니다.

사과게임의 방 코드·준비 단계·공유 seed·진행도 동기화 구조를 참고했습니다. 통신은 **PeerJS 1.5.5 / WebRTC**를 사용합니다. Firebase나 기존 사과게임 데이터베이스·랭킹에 접근하지 않습니다. PeerServer Cloud는 연결을 중개하고, 경기 상태는 두 브라우저에서 유지합니다.

친구끼리 즐기는 비랭크 경기입니다. 방장이 상태 변경을 순서대로 처리하며, 결과는 방장에게 먼저 접수된 종료 이벤트로 확정합니다. 서버가 조작을 검증하는 랭크 시스템이 아니므로 아주 근접한 결과에는 지연 차이가 있을 수 있습니다. 대전 승패는 기록실의 별도 대전 탭에 남고, 솔로 최고 기록에는 포함하지 않습니다. 연결 중단은 승률에서 제외합니다.

화면 잠금·탭 종료·새로고침으로 연결이 끊기면 경기를 중단합니다(무승부). 재접속 시 새 방을 만드세요. 양쪽 화면을 켜 두세요. WebRTC가 제한된 학교/병원/회사 네트워크에서는 연결에 실패할 수 있으며 이 경우 다른 네트워크를 사용하세요. 카메라·마이크 권한은 필요하지 않습니다.

새 버전은 확장된 증강을 지원하는 별도 방 프로토콜을 사용합니다. 이전 버전을 열어 둔 친구는 새로고침한 뒤 새 방을 만들어 주세요.

## 기록실과 자랑하기

- 상단 **기록실**에서 최근500판과 난이도별 솔로 최고 기록을 확인합니다. 보관된 경기 기준 승률·연승을 제공합니다. 500판에서 밀려난 최고 기록도 보존합니다.
- **솔로 / 친구 도전 / 1대1 대전**을 구분합니다. 중도 재시작·이탈은 중도 종료, 대전 연결 종료는 연결 중단으로 남습니다. 진행 중 스냅샷을 저장해 탭을 닫아도 마지막 탐사 진행률을 남깁니다(게임 이어하기 기능은 아님).
- 기존 작은9/12/16 보드 최고 기록은 별도 참고 기록으로 표시하고 새 큰 보드와 비교하지 않습니다. 기존 저장 키를 지우지 않습니다.
- 결과 화면 또는 기록실의 경기를 누르면 **1200×675 PNG 결과 카드**를 저장할 수 있습니다. 지원하는 기기에서는 기본 공유 창으로 이미지·문구·링크를 공유합니다. 공유 창을 지원하지 않으면 PNG 다운로드·문구 복사로 대체합니다.
- 솔로·친구 도전 기록의 **도전 링크**는 같은 배치·첫 칸·증강 후보를 재현합니다. 받은 사람이 시작을 누르고 첫 증강을 고르면 원래 첫 칸에서 자동 출발합니다. 완주 기록은 상대 시간과 비교합니다. 연습 가능한 친구 도전은 솔로 최고 기록에 들어가지 않습니다.
- 대전 결과는 카드·결과 문구를 공유합니다. 대전의 첫 자유 증강 선택 조건은 일반3택1과 다르므로 대전 결과에서 동일 보드 도전 링크를 만들지 않습니다.
- **기록 백업 / 백업 복원**으로 JSON 파일을 내려받아 다른 기기에 옮길 수 있습니다. 복원 시 기존 기록과 합치고 중복은 제거합니다. 파일은 브라우저 안에서 읽으며 서버로 보내지 않습니다.
- 계정·클라우드 자동 동기화·공식 온라인 순위표는 없습니다. 사이트 데이터 삭제 전 백업하세요. 공유 결과는 개인 플레이 기록입니다. 저장이 차단되면 오류를 표시하고 이번 세션의 결과 카드·백업은 계속 사용할 수 있습니다.

## iPad 레이아웃

태블릿·데스크톱에서는 상단바, 통계, 조작부와 보조 패널을 최소 높이로 압축하고 남는 공간을 게임판에 우선 배정합니다. 보드는 ResizeObserver로 남는 너비와 높이 중 작은 값에 맞춰 정사각형을 유지하며, 30×30 특이점도 가능한 한 큰 칸으로 표시합니다. 정밀 터치 확대 기능은 제거했습니다. 휴대폰에서도 상단 요소와 여백을 줄여 화면 폭을 최대한 게임판에 사용합니다.

## 개발 및 검증

빌드 과정이 없는 HTML/CSS/ES module 앱입니다. 멀티플레이를 선택할 때 로컬 번들 `vendor/peerjs.min.js`를 로드합니다(MIT, 라이선스 동봉). Google Fonts 로딩이 안 되면 시스템 글꼴을 사용합니다.

```sh
node serve.mjs
# http://127.0.0.1:4173
node --test
```

Node.js 20 이상 권장. 총 34개 테스트는 10종의 능력·횟수·무효 대상·종료 후 사용 방지·공정한 증강 후보·기록 보존/병합/백업·도전 링크 검증과 더불어 모든 난이도 무작위 보드의 지뢰 수·첫 클릭·숫자 정합성, 깃발, 보호막, 스캐너, 드론, 승패, 깃발 모드 주변 열기, 동일 seed 보드, 방 정원·준비·결과 확정을 확인합니다.

GitHub Pages는 `main` 브랜치 루트에서 정적 파일을 제공합니다. 기록은 기기에 저장되며 공유·백업은 사용자가 선택할 때 실행합니다. 멀티플레이에서는 연결 중개 서비스와 연결 정보가 교환되고 상대와 방 코드·게임 seed·능력 선택·진행도·결과가 전달됩니다. 기록 저장이 차단된 환경에서도 싱글 플레이할 수 있습니다.
